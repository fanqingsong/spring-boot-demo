# Spring Boot Demo 初学者学习指南

本指南配合仓库内各 `spring-boot-demo-*` 子工程使用，帮助你在**读代码 → 改代码 → 运行验证**的循环中系统入门 Spring Boot。教程与龙果学院 [Spring Boot 全集](http://www.roncoo.com/course/view/c99516ea604d4053908c1768d6deee3d#boxTwo) 章节对应；完整模块对照见根目录 [README.md](../README.md#demo-模块列表)。

**分册文档（推荐）：** 每个 demo 一篇，见 [docs/demos/README.md](demos/README.md)。

---

## 1. 学习前准备

### 1.1 基础知识

建议已具备：

- Java 基础（类、接口、注解、Maven 依赖概念）
- 了解 HTTP（GET/POST、URL、JSON）
- 可选：SQL 基础、HTML 模板概念

### 1.2 软件环境

| 工具 | 建议版本 | 说明 |
| --- | --- | --- |
| JDK | 8（1.8） | 各 demo 的 `pom.xml` 中 `java.version` 为 1.8 |
| Maven | 3.x | 构建与运行 |
| IDE | IntelliJ IDEA / Eclipse + STS | 导入**单个**子模块目录为 Maven 项目 |

本仓库基于 **Spring Boot 1.4.x**。学习原理不受影响；若你之后做新项目，请优先参考 [Spring Boot 当前文档](https://docs.spring.io/spring-boot/)（配置项名、部分 API 会有变化）。

### 1.3 后期章节可能需要的中间件

按学习进度再安装即可，不必一开始全部就绪：

| 中间件 | 大致从哪一讲开始需要 |
| --- | --- |
| MySQL | 第 13 讲起（JdbcTemplate / JPA / MyBatis） |
| Redis | 第 17 讲起 |
| MongoDB | 第 18 讲起（部分 demo 使用嵌入式 Mongo） |
| ActiveMQ | 第 21 讲 |
| RabbitMQ | 第 22 讲 |
| 邮件 SMTP | 第 24 讲 |

配置文件多在 `src/main/resources/application*.properties` 或 `application*.yaml` 中，**先把地址、账号改成你本机环境**再启动。

## 2. 仓库怎么组织

- **每个子目录是一个独立的 Maven 工程**，没有根级聚合 `pom.xml`。
- 命名规则：`spring-boot-demo-{章节号}-{序号}`，例如 `spring-boot-demo-03-2` 表示第 3 讲的第 2 个示例（YAML 配置）。
- 早期示例（约 02～05）包名多为 `com.roncoo.education`；从 Web 综合示例（约 06 起）多为 `com.roncoo.example`，后面会在前一讲基础上**累加**功能，便于对比 diff。

典型目录：

```text
spring-boot-demo-XX-Y/
├── pom.xml                          # 依赖与 Spring Boot 版本
├── src/main/java/                   # 启动类、Controller、Service、配置类
├── src/main/resources/              # 配置文件、静态资源、模板、MyBatis XML
└── src/test/java/                   # 单元测试（可选阅读）
```

**启动类**：查找带 `@SpringBootApplication` 的类，例如 `SpringBootDemo21Application.java`。

## 3. 如何运行一个 Demo

在**该 demo 目录下**执行：

```bash
cd spring-boot-demo-02-1
mvn spring-boot:run
```

或在 IDE 中右键启动类 → Run。

默认端口多为 **8080**（多环境配置里可能为 8081、8888 等，以当前激活的 `spring.profiles.active` 为准）。看到日志中出现 `Tomcat started on port(s): 8080` 即表示启动成功。

**验证第 2 讲 REST 接口示例：**

```bash
curl http://localhost:8080/index
curl "http://localhost:8080/index/get?name=roncoo"
curl http://localhost:8080/index/get/1/zhangsan
```

**学习建议：**

1. 先**只读**启动类 + 一个 Controller，猜请求会返回什么。
2. 启动应用，用浏览器或 `curl` 验证。
3. 改一行代码（如返回字符串、端口），再运行，观察变化。
4. 与**上一讲** demo 用 IDE 对比（Compare with…），看本讲新增了哪些类与依赖。

## 4. 推荐学习路线（分阶段）

按顺序学习效果最好；同一讲内 `-1`、`-2` 两个工程时，建议都跑一遍。

### 阶段 A：入门与配置（第 2～5 讲）

| 目录 | 本阶段要掌握什么 | 建议重点看的文件 |
| --- | --- | --- |
| `02-1` | 最小 Web 工程、`@RestController`、路径变量与请求参数 | `*Application.java`、`controller/IndexController.java` |
| `03-1` | `application.properties`、自定义配置、`@Value` 注入 | `resources/config/application.properties`、Controller 中的 `@Value` |
| `03-2` | YAML 格式、层级配置 | `application.yaml`、`config/application.yaml` |
| `04-1` | 多环境 profile（dev/test/prod） | `application.properties`、`application-*.properties` |
| `04-2` | YAML 多文档（`---` 分隔） | `application.yaml` 中 profile 段 |
| `05-1` | Logback 日志、按环境切日志配置 | `logback-roncoo.xml`、`logging.config` |

**阶段小结：** 会改配置、会看日志、会用 profile 区分环境。

## 5. 通用读代码方法（每讲都适用）

1. **看 `pom.xml`**：本讲新引入了哪些 `starter`（web、jdbc、redis…）。
2. **看配置文件**：端口、数据源、中间件地址、激活的 profile。
3. **看包结构**：
   - `controller` / `web`：对外 HTTP
   - `service`：业务与事务
   - `dao` / `mapper` / `repository`：数据访问
   - `util/configuration`：Java 配置类（替代大量 XML）
4. **看测试类**：`src/test/java` 里常有启动上下文或接口测试示例。
5. **对比上一讲工程**：在 IDE 中对两个模块目录做目录对比，比从头通读更高效。

## 6. 常见问题

**Q：Maven 下载依赖很慢？**  
A：配置国内 Maven 镜像（阿里云等），或 IDE 中设置 Maven settings.xml。

**Q：端口 8080 被占用？**  
A：修改当前 profile 下的 `server.port`，或关闭占用端口的进程。

**Q：MySQL 连接失败？**  
A：检查服务是否启动、库名是否存在、账号密码与 URL 是否一致；MySQL 8 驱动类名可能与老示例不同，必要时查阅当前驱动文档。

**Q：Redis / MQ 连不上？**  
A：先确认中间件已启动；再对照 `application-dev.properties` 中的 host、port、密码。

**Q：为什么有的 demo 包名是 `education` 有的是 `example`？**  
A：历史原因，早期章节为独立小示例，后期为延续的「综合项目」结构，不影响学习。

**Q：和 Spring Boot 3 / Java 17 差别大吗？**  
A：核心概念一致（自动配置、starter、注解 MVC）。升级时注意：`javax.*` → `jakarta.*`、部分配置键更名、Springfox Swagger 需换为 springdoc 等。本仓库适合**理解 Spring Boot 思想**，新项目请用新版本官方文档对照迁移。
